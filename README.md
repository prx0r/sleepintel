# sleepintel — the sleep-channel incubator and organism

Theory + registry + feedback loop for a 56-channel sleep network.
Renders nothing — engines do that. Decides what gets rendered, tracks
what happened, grows the network.

Start: `docs/THESIS.md` → `docs/GLOSSARY.md` → `docs/ENGINES.md` →
`registry/channels.yaml` → `docs/GRAPH.md` → `docs/ORGANISM.md` →
`docs/INCUBATOR.md`. Validate: `python3 scripts/validate.py`.
