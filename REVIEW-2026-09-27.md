## TL;DR — what's happening

**sleepintel is the brain of a planned 244-channel sleep-YouTube network. It decides
what gets made, tracks what happened, and grows the network. It renders nothing.**

- Machinery is largely **built but uncalibrated**: scoring, queue, Jev-gated
  actuation, rerank, classify, ideas, fisher, 3 versioned contracts, 244-channel
  registry, 18 hypotheses, 9 templates, 10 voices (spec only).
- **Zero ground truth**: 0 resolved hypotheses, 0 aired pilots from the new system.
  EV numbers are ordinal (ranking), not cardinal (real RPM predictions).
- Current phase per `docs/DEV_PLAN.md`: **Phase 1 tail** (contracts). Three tests
  block everything else: brief→sleepvids handshake, quota ledger reconciliation,
  review-state parity. Phase 2 (calibration), 3 (gated autonomy), 4 (learning) not started.
- **tubeintel is the senses**: 27 competitors, 129 videos, quota-cheap collector.
  Real value delivered (signals, steals, labels), but ledger understates true spend
  ~6.6× (search logged as 1, costs 100) and ~71 newer videos have `duration_s: 0`.
- **sleepsearch and sleepvids do not exist as repos.** They are roles in docs:
  SCOUT (other agent, 40 ideas imported) and STRUCTURE (brief consumer). `powvid`
  is the real HANDS (render factory, 19 tests green). `influence` is the claimed FACE
  (upload unlisted→public) but has **zero references** back to sleepintel — link is
  one-directional aspiration, not working integration.

## What's interesting / what surprised us

1. **The organism diagram is the best doc in the system** (`docs/ORGANISM_LINKS.md`,
   `ORGANS.md`, `MAP.md`): `sleepsearch (SCOUT) → tubeintel (SENSES) → sleepintel
   (BRAIN) → sleepvids (STRUCTURE) → powvid (HANDS) → influence (FACE) →
   tubeintel measures → sleepintel resolves`, with `noslop (IMMUNE)` and `qprivately
   (LAW)` named. Git is the blood. Contracts live in sleepintel, implementations
   live where they execute. This is genuinely good architecture — file-coupled, no
   network, auditable.
2. **Jev gating is real, not theatre**: `jev/decisions.json` pins `typesafe/jev-1.13`
   with 6 decisions (pilot-proposed Choice, pre-publish Noul, render-step Score,
   template-pick, voice-pick, voice-compatibility). `actuate-1` receipt shows a real
   HOLD (`iterate 0.40` → fail-closed). That said, `AUTONOMY.md` self-verdict is
   honest: receipts exist but no actuator reads them yet.
3. **tubeintel already found usable steals** (`docs/RESOLUTIONS.md`): P2 supported
   (median 2.4h, story 1.5–3h), P4 strong (counting formats dense at top), 5 reusable
   steals (`Fall Asleep to X on Y`, `100 X Facts…`, `What It Was Actually Like To…`,
   `No Adverts`, `entire X explained`). 90 videos labeled with sleepiness baselines
   (rain 1.9 > facts 1.37 > place 1.11, per latest commit `6666846`).
4. **Concentration risk is stark**: E5 (talk) = 157/244 channels; MIND+STORY =
   185/244 shelves; 130 channels are `compile` readiness (not pilot-ready). E4
   (ambience — cheapest, build-first per `ENGINES.md`) has only 5 channels. E6
   (freshness) has 1.
5. **30 commits unpushed** on sleepintel `master...origin/master [ahead 30]`
   (+3767/-24). tubeintel is clean. Push needs PAT — noted in `MAP.md` push ledger.

### 1.3 Controller cycle (per `docs/CONTROLLER.md` + `ORGANISM.md`)

```
SCORE (EV = readiness × shelf_band × moat × engine_economy × demand)
→ QUEUE (P × RPM + projected views ranges)
→ GATE (Jev Choice promote/iterate/kill/other; promote+conf≥0.75 or HOLD)
→ EMIT (assembly manifest → sleepvids-shape brief data/queue/<id>.brief.json)
→ MEASURE (tubeintel: videos.list + Analytics, raw → data/yt/<date>/)
→ RESOLVE (playing_out? → verdicts PROMOTE/ITERATE/KILL/SPLIT)
→ LEARN (weights shift, commit cites verdict; calibrate.py Brier)
```

- Verdict rules: PROMOTE = CTR≥median AND AVD≥25% @14d; ITERATE = one variable;
  KILL = below both @30d; SPLIT = 3× series→own channel. Library-asset exception
  to views-agnostic kill (Phase 3).
- Ontology: EXPOSED→OPENED→HELD→STAYED→RETURNED (per-video)→JOINED.
- Phase 2 = UCB1 bandit (20% explore / 80% exploit). Phase 3 = RPM discipline.
