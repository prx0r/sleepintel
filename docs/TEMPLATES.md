# TEMPLATES — cross-channel formats (v1, 2026-09-26)

A template applies across channels (unlike engines, which produce, and
shelves, which group). Same template, different corpus = new series.
Proof: "Level 1 to 100 Philosophy Concepts" 4.8M views.

- 1-TO-100 (progressive complexity): paradoxes, thought experiments,
  biases, constants, elements, concepts, phenomena, adaptations. Completion
  + progression + predictable + clickable.
- HISTORICAL SWEEP (origin to present): word histories, album lore, myths.
- EXPLAINER (one idea, slowly): maths, AGI, paradoxes. Bub's lane.
- LIBRARY SEASON (chapter N of M): books, diaries, grimoires.
- ENTRY SERIES (entry N of M): reference, flags, elements, timetables.
- WORD FORMAT (7 beats + goodnight): etymology, roots, phrases, grammar.
- SILENCE+TITLE (8hrs, joke in the title): the title IS the content.
  "The awkward silence after…" — comedy writes the click, silence sleeps.
- EVENING (host + music + wedge): composer evenings, covers.
- JOURNEY (picture…): guided visualizations, daimon encounters.

New template rule: three channels want the same shape, or it stays a one-off.
Templates resolve in ANALYTICS like tags (which shapes hold people?).
