# GITHUB STEALS (mined 2026-09-26 — adopt, don't admire)

## Adopt now (cheap, proven)

1. Uniqueness gate (youtube-bgm-pipeline): score every render 0-100 on
   variation before publish; low score = new variant, never override.
   Template-farming protection + AI-slop compliance in one check.
2. Private-first upload (same): uploads land private, human flips to public.
   Keeps the kill law physical.
3. SFX tags in scripts (whoff factory): `[SFX:rain]` in narration = fade-in
   event under the voice at that point. Sound design lives in the script.
4. Bed recipes as data (ambient-content-pipeline): mix specs are JSON files
   (layers, volumes, LFO, crossfades), not code. Our BEDS dict becomes files.
5. Title formula (whoff): [Duration] [Sound] Sleep — [Outcome], [Feature].
   Tag tiers: always / rotate / long-tail. Adopt for E4 uploads.
6. Narration premium (whoff real numbers): ambient $8–10 RPM vs narrated
   $10–15. Hosted beats abandoned, quantified — feeds H-HOST.
7. Channel config files (faceless-video-engine): one config per channel
   (niche, persona, visual rules). Our registry already does this — validated.
8. Backoff everywhere (all): every API boundary retries with jitter.
   Already in voice.py; extend to all collectors.

## Intro pack pattern (the user's point, now law)

Build once, theme forever: jingle sting + wedge + title card + bed recipe
= one pack. New channel = new accent + voice + corpus on the same pack.
Filed in STYLE.md. Textured foley (page, pencil, rain-edge) layers into the
pack, never into episodes.
