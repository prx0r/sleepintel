# COMPLETION SCIENCE (mined 2026-09-26)

## Mechanisms (named, real)

- Zeigarnik effect: unfinished tasks dominate attention — an open series
  itches until closed. Our libraries are years-long open loops.
- Sunk cost: episode 12 watched → episode 13 obligatory.
- Appointment viewing: same release rhythm trains return (series loyalty
  up to 5.2x standalone).
- Completion → subscribe: finishers convert hardest. Completion rates:
  60-70% (4-6 eps), 40-50% (8-12), 30-40% (long).
- Session chaining: autoplay + end screens + pinned playlist link remove
  every decision between episodes.

## Sleep adaptations (daytime tactics, rewritten for night)

- The bridge is a lullaby: resolve tonight's tale fully, then whisper
  tomorrow's ("tomorrow: the firebird") — satisfaction + pull, no cliffhanger
  anxiety. Never withhold; always promise.
- Number every episode visibly ("Night 47 of 100"): the finish line IS the
  mechanic. Count UP (progress) not down (pressure).
- Series Playlists (not regular): autoplay carries sleepers; YT favors them.
- Batch rule: 3-4 episodes banked before episode 1 airs — momentum must
  never wait on production.
- Length discipline: same runtime ± minutes per series. Sleepers set clocks
  by you; variance breaks trust.
- First-series length: 4-8 to learn, then libraries scale (our corpora are
  12-3,650 deep — start short: Meditations 12, then Darwin 30+, then Pepys).

## Kill metrics (from the research)

Ep1→2 under 70% = premise misfire. Mid-series cliff at one transition =
that episode underdelivered (fix the bridge). Gradual decline = normal.
Completion under 30% on short series = arc problem, kill or rebuild.
