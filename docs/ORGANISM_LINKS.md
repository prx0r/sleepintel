- sleepsearch → tubeintel: findings JSON (channel, evidence, shelf guess).
- tubeintel → sleepintel: signals.json (structures, demand, evidence rows).
- sleepintel → sleepvids: brief JSON (video node shape: id, channel, title,
  voice, pace, mechanisms, shelf, engine, SEO skeleton, gated_by).
- sleepvids → powvid: assembly manifest (schemas/assembly.v1).
- powvid → dash/R2: video + meta + thumb. influence reads dash for review.
- tubeintel → sleepintel: metric snapshots → verdicts → weight shifts.

## Freshness rule

(schemas/, jev/); implementations live where they execute. Format drift =
immediate flag, never silent adaptation.
