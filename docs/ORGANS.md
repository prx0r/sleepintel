# ORGANS — the body, not the stack (v1, 2026-09-26)

No HydraDB needed. Git + YAML + SQLite already is the shared memory
(receipts, registries, snapshots — content-addressed, replayable).
Services would add ops burden for zero gain. Organs share one bloodstream:
the registry formats.

- powvid = HANDS. Renders what manifests say. Knows nothing downstream.
- sleepintel = BRAIN. Hypotheses, queue, verdicts, Jev gates. Decides.
- tubeintel = SENSES. Competitor pulls, DNA rows, quota ledgers. Sees.
- influence = FACE. Each channel is an identity: voice persona + accent +
  wedge + jingle + host flavor. Passports as the shape of any appearance.
  Adoptable patterns: hloop (bank prediction BEFORE decide — preregistration
  with teeth), quarantine (untrusted intake stays untrusted), trend-radar
  spec (trends → ranked candidates = fisherman design), influencer-studio
  spec (job queue → artifact + receipt = content-gen design), qpbot worker
  layer (Pi sessions, subagent spawn/monitor/audit, missions, vault-scoped
  keys — the pattern for driving queues; no local copy, adopt the shape).
  Dashboard-as-harness law holds everywhere: not visible = not done.
  Our studio builds on OUR dash with these patterns; no literal pi harness
  found (community pi-jev reviewed separately).
- noslop = IMMUNE SYSTEM. Uniqueness gate, slop detection, quality floor.
  Nothing ships that fails the body.
- sleepsearch = SCOUT. Queries, niches, keywords ahead of the main force.
- qprivately = LAW. Transition equation: state changes ONLY when all gates
  pass. The constitution above every organ. No scalar fitness trading
  quality for cost — ever.

Bloodstream: registry YAMLs (channels, competitors, voices), assembly
manifests, decision receipts, metric snapshots. Any organ reads any other
organ's output by format, never by API. Git is the circulation.
