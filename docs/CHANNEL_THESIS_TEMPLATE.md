# CHANNEL THESIS — template (copy per channel, same headings always)

## Promise (one line)
What the viewer gets, in their words.

## Why it works (mechanism)
The sleep/psychology mechanism: which need, which load, which comfort.
Cite the thesis law it rides (place / difficulty / hosted / ritual).

## Sources (tiers)
- Tier 1 — curated/held now (paths, not vibes).
- Tier 2 — APIs/pipes already owned.
- Tier 3 — to acquire (with the exact next action).
Table form: source | what it provides | status (mirrors the filed exemplars).

## Content structure (episode format, numbered beats)
The per-episode ritual, beat by beat, ending in the shared goodnight
("And now you know. Sleep well."). Same beats every episode — ritual IS
the product. This section is mandatory; a thesis without it is a draft.

## Pipeline (engine + steps)
Engine + numbered steps + per-episode cost + runtime. If a step needs a
key/cash/build, name it — no silent dependencies.

## Retention mechanic
Why night two happens (habit loop in one sentence).

## Rights
PD / permission / discuss-only / produced — with the proof or the queued action.

## First 3 pilots
Concrete titles. Verdict slots pre-opened.

## Kill criteria
What numbers kill it (from ORGANISM rules, channel-specific thresholds).
