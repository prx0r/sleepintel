# ROADMAP — 30 days (adopted 2026-09-26)

## Weekly cadence (every week, same rhythm)

- Monday: inbox triage — promote or kill.
- Tuesday: engine work — one engine only.
- Wednesday: pilots — 3–5 renders across channels.
- Thursday: verdicts — promote / iterate (one variable) / kill.
- Friday: queue re-rank + next week planned.

## Rule of the month

Three engines working + ten pilots measured beats fifty-six channels
announced. Registry makes it computable, incubator makes it killable,
engines make it scalable. Start with Account A (lowest risk, most channels).
