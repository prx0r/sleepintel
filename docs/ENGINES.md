# ENGINES — the six parents (v1)

An engine is built when three channels want the same thing current engines
can't do. No engine for one channel. Status honest per engine.

## E1. hosted-music — the evening
Contract: host intro + music whole + host bridges + wedge every frame +
goodnight ritual. Voice in gaps, never over music.
Inputs: PD/MIDI audio or Suno/ACE renders + lore/theory scripts.
Serves: composer-evenings, sleepy-covers, deconstructed, classical-charts.
Status: spec'd + proven once (Satie evening, 730s).

## E2. reading — PD text to sleep
Contract: slow TTS + ambient bed + one whiteboard scene per passage.
The workhorse. Inputs: any verified PD text + accent + art family.
Serves: 28 channels (steiner, daimon-r, channeled-r, alchemy, angel,
kashmir, sufi, dialogues, saiva, ficino, spell, tarot, iching, meditations,
spanda, plotinus, buddha, gnostic, myth, fairy, folklore, myth+, cassiopaean,
kabbalah, theosophy, hindu, taoist, christian-myst, egyptian, manly-hall).
Status: BUILT + piloted (26 SLEEP videos).

## E3. guided — journeys ("picture…")
Contract: yoga-nidra narration over drone + near-static visual. No plot,
only descent. Inputs: a cosmology map + journey script.
Serves: daimon encounters, manifestation, theurgy, kabbalah-tree, spanda-body.
Status: scripts only — needs run mode (long scenes, drone bed, no captions).

## E4. ambience — loops, no narration
Contract: synthesized bed + slow visual loop + ship. Cheapest per hour.
Inputs: a place + a bed recipe. The room IS the content.
Serves: fly-on-wall, anti-sleep-war, anti-sleep-arguing, rain-variants.
Status: UNBUILT — simplest build on the board.

## E5. talk — host discusses
Contract: research brief + host essay + whiteboard diagrams. For topics,
not texts. Inputs: brief + script. Same renderer as E2, essay inputs.
Serves: lore, genius, maths, agi-scenarios, shoggoth, agi-sleep, niche-psych,
snooze, conspiracy, truth, company, cosy-past, near, soul, news, channeled-d,
school. Status: BUILT (running).

## E6. freshness — daily scan to render
Contract: web scan → brief → E5 render, same-day. Inputs: query packs.
Serves: good-news (primary). Status: UNBUILT — scan-to-brief step only;
render side exists.

## Build order (revised 2026-09-26 — review adopted)
E2 done. E5 running. E1 proven once. **E4 FIRST** (cheapest per hour,
leave-it-on = highest watch time, simplest build). Then E6, then E3.
