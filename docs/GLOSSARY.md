# GLOSSARY — the objective system (v1)

- **Engine.** A parent production system: fixed inputs, stages, and output
  grammar that can serve many channels. Expensive (spec + run mode). Six
  exist: hosted-music, reading, guided, ambience, talk, freshness.
- **Channel.** An expression of an engine: corpus + accent + art family +
  host flavor + title grammar. Cheap (a brief + a pilot). 56 indexed.
- **Campaign.** A launch unit: one channel (or merged set) with tagline,
  first episode, and queue. Ten launched.
- **Pilot.** The first video of a channel, emitted with tracked IDs, judged
  once by the owner. One variable per round; generator never judges.
- **Verdict.** promote | kill | iterate, recorded with reason. Dead ends are
  data — retained, never deleted.
- **Corpus.** The verified source bench behind a channel (PD texts, papers,
  recordings). No channel without one.
- **Accent.** One signature color per channel on the shared black +
  warm-white base. Still sleepy, instantly recognizable.
- **Organism.** The network plus its feedback loop: pilots out, metrics in,
  verdicts applied, queue re-ranked. sleepintel is its nervous system.
- **Subengine.** A shared run-mode inside an engine (same stages, params,
  contracts). Channels sharing one differ only in corpus + accent + flavor.
- **Shelf.** An audience umbrella (Spiritual, Esoteric, Story, Mind, Music,
  Place, Fresh). Engines are how we make; shelves are how viewers browse.
- **Tag.** Type (production shape) or mechanism (desire) on a channel row.
  Feedback resolves per tag — the granular layer under verdicts.
- **Video.** A child of a channel: tracked ID, variant, hashes, metric
  snapshots, verdicts. Published videos live-update from the API.
- **Idea.** Next slot per channel from its subengine (scripts/ideas.py).
  Corpus-state resolves at brief time; slots are structural.
