# THE LIBRARY FORMAT — completionism as retention (filed verbatim, 2026-09-26)

## The insight

Every other sleep channel is infinite by design. Libraries end. Endings make
people stay for the last page. Completionism is a retention mechanic nobody
in sleep uses. The loop: find library → chapter 1 → subscribe → follow the
journey → last page → completion → tell friends → next author. Beginning,
middle, end — not infinite scroll.

## The format

Channel name: "X's Library" — one author's complete works. Structure: Book 1,
Book 2, Book 3... until finished. Episodes: one chapter each. Completion:
subscribers finish together ("we did it"). After: new library starts.

## The libraries (all PD via Gutenberg unless noted)

Darwin (~30-40 eps, 3-4 months): Origin, Beagle, Descent, Expression,
Life and Letters (+ Darwin Online 50,000+ pages). Da Vinci (~50 eps, 5-6
months): Notebooks. Pepys (3,650 entries or compilations, years): Diary
1660-1669. Marcus (12 eps, 12 weeks): Meditations (Long/Hays PD).
Also: Seneca ~30, Epictetus ~20, Plato ~30, Aristotle ~25, Confucius 20,
Lao Tzu 81 chapters, Virgil 12, Homer 24+24, Dante 100 cantos, Milton 12,
Shakespeare 37 plays.

## The Forbidden Library (grimoires, chapter by chapter)

Picatrix (PD), Key of Solomon (1889 PD), Abramelin (1897 PD), Raziel (PD),
Munich/Swiss manuals (PD), Heptameron (1655 PD), Arbatel (1575 PD),
Libellus Nigromantiae (PD). Gardner's Book of Shadows: partial PD, caution.
Episode: chapter → context → text → commentary → goodnight. Names:
The Forbidden Library / Grimoire Channel / Black Library / Occult Archive.
Why: forbidden + finite + mysterious + communal + unique.

## The cross-sell (the moat in motion)

Darwin → Da Vinci → Pepys → Picatrix → Solomon → ... Each library a season,
each ending a reason to start the next. Completionism is the moat: the only
sleep product with beginnings and ends, journeys taken together, and a
reason to return that isn't novelty.
