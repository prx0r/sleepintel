# CHANNEL PIPELINE — idea to unlisted (v1, 2026-09-26)

Every channel runs the same spine, its own corpus. Human signs off;
nothing publishes itself.

1. QUEUE — ideas/next.json + sleepsearch imports per channel. Jev rerank
   picks the next pilot (Choice, recorded).
2. BRIEF — corpus verified, template picked (Choice), variant set.
3. PRODUCE — engine renders (powvid): video + thumbnail frame + wedge.
4. PACKAGE — title/description/tags/hashtags drafted (dash review studio),
   Jev-scored variants where valuable. Chapters where serial.
5. REVIEW — watch in studio, approve/reject with reason (dash /review).
   Rejections need reasons (verdict data).
6. UPLOAD — influence stack manages upload as UNLISTED (videos.insert,
   private-bucket quota). Human sign-off flips to public. Never direct
   to public, never auto-publish.
7. MEASURE — tubeintel pulls metrics; snapshots join hypotheses.
8. VERDICT — resolve, re-rank, next idea dequeued.

Upload management lives with influence (identities own the channels that
publish). sleepintel emits manifests; influence executes publishes.
