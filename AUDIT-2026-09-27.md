## 3. Jev audit — the client, the decisions, every call site

### 3.1 `scripts/jev.py` (79 lines — mostly sound, with dead code)

- Pin real: `MODEL = "typesafe/jev-1.13"`, endpoint `openrouter.ai/api/alpha/decisions`.
  Receipts stamp resolved `jev-1.13-20260917`. Good.
- Retries narrow: 3 attempts `1s→2s→4s` but **only on 429/529**. 401/400/500/DNS/120s-timeout raise immediately; most callers don't handle it.
- Single point of failure: `_key()` reads `/root/sleepintel/.env` or
  `/root/.openrouter_key` only — no `os.environ` support. Only the `.env` (mode 600)
  has it. One file holds three repos hostage (tubeintel + powvid piggyback via
  `sys.path` hack + shared-key fallback).
- **Dead code:** `fail_closed()` (returns `"human"`, zero callers), `band_noul()` /
  `band_confidence()` (zero production callers — only `tests/test_jev.py`). Every
  call site re-implements thresholds inline and they've **diverged** (0.5s invented
  twice, nowhere in `decisions.json`).
- **Stale docstring:** "no confidence field exists — never invent one." False:
  every receipt has `confidence`, five call sites read it, and `calibrate.py:25`
  invents it via `abs(noul-0.5)*2`.
- **Thin receipts:** `record()` logs `id/state/questions/answers/action` only — no
  timestamp, model, thresholds applied, band outcome, or cost. Can't reconstruct why.

## 4. Top 5 fixes that make it real (ordered)

1. **Close one loop end-to-end.** One pilot past actuate → first brief in
   `data/queue/` → sleepvids brief-reader + `gated_by` field → one render. One full
   pass beats all docs.
2. **Wire rerank into `queue.py`, fix receipts.** Record action-taken (kept order vs
   applied pick), not raw pick. A lying audit log is worse than none.
3. **Run calibration once, for real.** Rename 6 template rows to
   `calibration_template-pick.jsonl`, fix the `labels.jsonl`-as-JSON bug, publish
   first accuracy-by-confidence table, move **one** threshold from vibes to data.
4. **Kill or implement the theatre.** Route every site through
   `band_noul`/`band_confidence`/`fail_closed` (single choke point) or delete them;
   Jev-drive `voice_matcher.py` + score gate or remove those decisions. Dead policy
   teaches everyone policy is optional.
5. **Harden provenance + failure modes.** `_key()` honors `os.environ`; every
   `decide()` gets try/except with declared fail direction; `record()` logs model,
   thresholds, band, timestamp, cost. Add error-path tests — all 11 pass today while
   covering zero failure behavior.
